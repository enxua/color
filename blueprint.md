# Color Palette Generator Blueprint

## Overview
A modern, interactive color palette generator that allows users to generate, lock, and copy colors for their creative projects.

## Features
- **Random Generation:** Generate 5 harmonious or random colors with a single click (Spacebar).
- **Locking:** Lock specific colors to keep them while regenerating others.
- **Copy to Clipboard:** Click on a color code to copy it instantly.
- **Responsive Design:** Works perfectly on mobile and desktop.
- **Visual Effects:** Smooth transitions, hover effects, and deep shadows for a premium feel.

## Design & Style
- **Typography:** Inter or system sans-serif for a clean, modern look.
- **Layout:** Full-screen vertical or horizontal bars depending on screen size.
- **Interactivity:** Micro-interactions on buttons and color bars.
- **Aesthetics:** Vibrant colors, subtle noise texture on background, and glassmorphism elements.

## Technical Details
- **Framework:** Vanilla JavaScript (ES Modules).
- **Styling:** Modern CSS (Flexbox, CSS Variables, :has selector).
- **Icons:** Inline SVGs for lock/unlock icons.
